# Vitta.Client

Workspace Angular com:

- `projects/core` → `@vitta/core` (modelos + serviços da API, compartilhado)
- `projects/web` → app web responsivo (`npm run start:web`, porta 4200)
- `projects/mobile` → app Ionic + Capacitor (`npm run start:mobile`, porta 8100)

`npm run build` gera os dois apps em `dist/`. `npm test` roda os testes do web.
