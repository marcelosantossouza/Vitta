Como a planilha deve estar?

Se a planilha da seguradora tem um layout próprio (abas, linhas antes do cabeçalho, nomes diferentes), crie um modelo com IA uma vez e reutilize todo mês.

Não consegue baixar a planilha? Use Colar do site: no site da seguradora, selecione a tabela (de preferência com a linha de títulos), copie (Ctrl+C) e cole (Ctrl+V). Se a tabela vier sem títulos, crie um modelo colando o mesmo texto.

Sem modelo, a primeira linha deve ter os nomes das colunas. Reconhecemos (sem diferenciar maiúsculas ou acentos):

  • Apólice / Proposta / Certificado (ou, se não houver, CPF) — obrigatória
  • Segurado / Nome — obrigatória
  • CPF, Produto / Plano, Prêmio / Valor, Status / Situação, Início da vigência

A primeira importação de cada seguradora vira a carteira base. A partir da segunda, o Vitta compara com o mês anterior e aponta as entradas, saídas e mudanças.
